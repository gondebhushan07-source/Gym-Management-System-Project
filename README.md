# Hand Tracking Project

A simple Python project that uses a webcam to detect and track hand movements in real time.

## Features

* Detects hands using a webcam
* Tracks hand landmarks
* Shows hand movements in real time
* Displays the number of detected hands

## Requirements

* Python 3.x
* OpenCV
* MediaPipe

## Installation

Install the required libraries:


pip install opencv-python mediapipe


## How to Run

1. Download or clone the project.
2. Open the project folder in a terminal.
3. Run the Python file:

```bash
python hand_tracking.py
```

4. Allow access to your webcam.
5. Place your hand in front of the camera.
